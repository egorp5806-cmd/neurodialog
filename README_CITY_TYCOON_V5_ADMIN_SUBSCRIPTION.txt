CITY TYCOON V5 — ADMIN + ОБЯЗАТЕЛЬНАЯ ПОДПИСКА

Что добавлено:
- Админ-панель внутри Mini App.
- ADMIN_IDS — список Telegram ID администраторов.
- Добавление обязательных Telegram-каналов.
- Проверка подписки через Telegram Bot API getChatMember.
- Экран «Подпишись, чтобы играть».
- Кнопка повторной проверки подписки.
- Включение/выключение обязательного канала.
- Удаление канала.
- Статистика: игроки, открытые комнаты, активные игры.
- Администраторы проходят без обязательной подписки.
- PostgreSQL сохраняется; новая таблица required_channels создаётся автоматически.

RENDER

Build Command:
pip install -r requirements_city_tycoon_v5.txt

Start Command:
python city_tycoon_v5.py

ENV:
BOT_TOKEN=токен_бота
DATABASE_URL=postgresql://...
WEB_APP_URL=https://твой-сервис.onrender.com
ALLOW_BROWSER_DEMO=false
INIT_DATA_MAX_AGE=86400
DB_POOL_MAX=12
ADMIN_IDS=123456789,987654321

ADMIN_IDS:
Укажи Telegram user ID администраторов через запятую.
Например:
ADMIN_IDS=123456789,987654321

КАК ДОБАВИТЬ КАНАЛ

1. Добавь бота в канал.
2. Для надёжной проверки сделай бота администратором канала.
3. В Mini App открой «🛠 Админ-панель».
4. В поле канала укажи:
   - публичный канал: @mychannel
   - приватный канал: numeric chat_id вида -1001234567890
5. Для приватного канала укажи invite URL вручную, например ссылку-приглашение.
6. Нажми «Добавить канал».

ПРОВЕРКА

Telegram Bot API getChatMember проверяет конкретного пользователя в каждом активном обязательном канале.
Статусы creator / administrator / member считаются подпиской.
Для restricted учитывается is_member=true.
Если хотя бы один активный канал не пройден, игровой API блокируется и пользователь видит экран подписки.

ВАЖНО

- Бот должен иметь доступ к проверяемому каналу. Для приватных каналов особенно важно добавить бота в канал.
- Для публичных каналов можно использовать @username.
- Не удаляй PostgreSQL: миграция required_channels создаётся автоматически.
- После изменения ADMIN_IDS на Render сделай redeploy/restart.
